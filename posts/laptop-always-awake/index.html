我的笔记本从不合盖，手机就成了云电脑

2026-11-25 · 3 分钟 · 1227 字 · Attack825
目录

  • 两个入口，各管一半

Agent 改变了我的生活方式。在等待朋友的十几分钟里，我把手机里攒了三天的两个 B 站视频链接发给了家里的电脑。朋友坐下来的时候，两篇整理的笔记已经好了。

先有一台不下班的电脑#

用远程的方式用 agent，实际是用远程的方式用自己的电脑。DSH 装在本机，能读写文件、执行命令、连 git 仓库，手机屏幕上那个页面只是把界面送到了手上，真正干活的是书桌上那台笔记本。所以第一步不在网络配置，在那台机器会不会自己睡着。

Windows 默认合盖就睡。关掉它：控制面板 → 硬件和声音 → 电源选项 → 选择关闭盖子的功能，把 接通电源 那一栏改成 不采取任何操作，再把睡眠设为 从不。屏幕可以照常关，机器不睡。

做完这些，这台机器就从工作站变成了服务器。有意思的是它仍然是那台工作站：我要坐下来干活，掀开盖子就是原来的桌面。

有人会问，为什么不直接租一台云服务器。省心的地方是不用管硬件，麻烦的地方是它碰不到我的文件。笔记库、代码、几个自己写的小脚本都在本机，把这些东西搬到服务器上是另一项工程，而 agent 的价值恰好在于它可以直接动它们。租一台机器装个 agent，和让 agent 住进自己的电脑，是两个不同的东西。

两个入口，各管一半#

我给它开了两道门，一窄一宽。

窄的是微信机器人插件。它把 DSH 变成一个聊天对象，我说一句，它做一件，回一句。适合的都是短活：把电脑静音、十点半提醒我、知识库推上去了吗。好处是通知和指令在同一个地方，微信本来就会响。坏处也明显，发不了长文本，看不了 diff，多轮改稿等于在聊天框里做手术。

宽的是远程访问插件。DSH 本来就是 web 应用，插件用 Cloudflare 隧道把本机端口映射到一个公网地址，手机浏览器打开就是电脑上的那个界面。

隧道这一环有个坑。默认的临时隧道每次断网或者启动都换一个域名，手机上还得重新登录。把隧道绑到自己的 Cloudflare 域名之后，地址固定了，用起来像一个正常网站。绑定域名后 Cloudflare 的节点也稳定许多。

两道门的分工不重叠：微信负责叫它，浏览器负责看它。要写清楚需求、要盯着改、要对比前后版本，我宁愿多花十秒打开浏览器，也不在聊天框里来回三轮说不明白。

例子：从视频到知识库#

手机上最常用的操作，是往里面丢链接。

起因很现实。视频里的东西留不下来，看完就忘，收藏夹越堆越多，最后等于没存。我想要的是看完之后留下一个能搜、能读、能引用的文件。所以我在 DSH 里写了一个 skill，触发方式就是发一个链接，加一句「帮我看看这个视频讲了啥」。它按固定顺序做四件事：

  1. 抓。先用 yt-dlp 取平台自带的字幕，B 站有 CC 字幕，部分视频有 AI 字幕。取不到就下载音轨。
  2. 转。音轨交给语音识别，出一份带时间戳的逐字稿。
  3. 摘。全文交给 DeepSeek，让它写摘要：这期讲了什么，有哪几个论点，哪几句要原样保留。
  4. 存。摘要在前、逐字稿在后，合成一个 Markdown 文件，写进 Obsidian 库里对应的目录，commit，push。

push 之后有两条路看结果。GitHub 的手机 App 能直接渲染 Markdown，表格、代码块、标题层级都在，适合在路上快速过一遍。如果要快速看一眼，直接在手机端浏览器的 dsh web 页面点击预览，就像电脑端一样。
